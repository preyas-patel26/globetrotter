# 🌍 GlobeTrotter

### Personalized Multi-City Travel Planning Platform

GlobeTrotter is a modern travel-planning web application that helps users create, organize, visualize, budget, and share personalized multi-city trips.

Instead of simply searching for destinations, GlobeTrotter allows users to build a complete travel experience — from selecting destinations and activities to organizing the itinerary, estimating expenses, viewing the journey on a calendar, and sharing the final trip.

---

## ✨ Features

### 🔐 Authentication
- User registration
- User login
- Password validation
- Protected application pages
- User profile management

### 🏠 Dashboard
- Personalized welcome section
- Upcoming trips
- Ongoing trips
- Recommended destinations
- Destination and activity search
- Quick "Plan a New Trip" action
- Budget overview

### ✈️ Trip Planning
- Create a new trip
- Add trip name and description
- Select start and end dates

### 📍 Multi-City Itinerary

### 🎯 Activity Planning

- Activity expenses

- Remaining budget calculation
- Over-budget warning

### 📅 Calendar & Timeline
- View trip activities by date
- Day-wise itinerary
- Activity timing
- City-wise planning
- Calendar visualization
- Timeline view

### 🌎 Community
- Explore publicly shared trips
- Search shared itineraries
- Discover travel ideas
- View other users' trips
- Copy an existing trip and customize it

### 🔗 Trip Sharing
- Publish an itinerary
- Generate a public/shared trip view
- Share trip details

### 👤 Profile

- Edit profile
- Manage preferences
